This site treats blog posts as Markdown files. The title, date, and description at the top of this file are used on the blog list and in the page header.

Write in the body as you normally would:

- Headings
- Lists
- Links
- **Bold** and *italic* text

When you save the file and rebuild, the post shows up at `/blog/hello-world/`.
