---
title: Why write pages in Markdown
date: 2026-08-12
description: Markdown stays readable in a text file and still becomes a normal web page.
---

Markdown is a good fit for a small site because the files stay easy to edit. You can keep About, FAQ, and blog posts next to each other, then generate HTML when you want to preview or publish.

A page only needs a little information at the top:

```md
---
title: About
description: A short summary for search and social previews.
---
```

Everything under that becomes the page content. HTML is allowed too, which is useful for buttons, forms, or a custom hero on the landing page.
